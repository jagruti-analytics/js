How I approach an analysis

Start with the decision

I ask what someone will do differently after seeing the numbers, then work backwards to the data and the chart.

Check the data first

Before building anything, I look for gaps, duplicates and definitions that don't match, because a polished dashboard on bad data misleads.

Say it plainly

Every dashboard I build leads with its main finding in a sentence, with the detail one click below.
